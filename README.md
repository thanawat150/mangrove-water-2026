# Mangrove Water Dashboard

แดชบอร์ดแผนที่น้ำ 40 แปลง ในจังหวัดระยอง จันทบุรี และตราด

**เปิดเว็บ:** https://thanawat150.github.io/mangrove-water-2026/

- ภาพรวมพื้นที่น้ำและสัดส่วนรายจังหวัด
- ตัวกรองจังหวัด รหัสแปลง และประเด็นตรวจสอบ
- คลังแผนที่ PDF ต้นฉบับ, PNG สำหรับเว็บ และ GeoPackage ทั้ง 40 แปลง
- รายงานที่มา ข้อจำกัด และการตรวจแก้ตามข้อมูลผู้ใช้

## ข้อมูล ณ 12 พฤศจิกายน 2569

เนื้อที่ตามตารางคุม 1,718.44 ไร่ พื้นที่มีน้ำขัง 148.76 ไร่ และพื้นที่ไม่มีน้ำขัง 1,569.68 ไร่

ตัวเลขไม่มีน้ำขัง = เนื้อที่ตามตารางคุม − พื้นที่รูปน้ำ หลังปัดทศนิยมสองตำแหน่ง รูปขอบเขตจริงอาจมีเนื้อที่ต่างจากสัญญา ดูหมายเหตุในแต่ละแปลง

2-STC ตรวจแก้เป็นเลนเปียกที่น้ำขึ้นท่วมถึงตามข้อมูลจากผู้ใช้ โดยแสดงพื้นที่มีน้ำขัง 0.00 ไร่ ไม่ใช่ข้อสรุปที่โมเดลยืนยันเอง มีการเว้นช่องต้นไม้ชัดเจน 15 จุดในอีก 5 แปลง

แผนที่สะท้อนภาพที่ใช้ ระดับน้ำอาจเปลี่ยนตามวันและน้ำขึ้นน้ำลง ไม่ใช่ผลสำรวจภาคสนามปัจจุบัน
